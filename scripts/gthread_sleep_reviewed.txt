# Reviewed sleeps for scripts/gthread_sleep_gate.py.
#
# Format:  path::qualname  # benign|pending <owner>: reason
#
# One entry covers the named function. A reviewed sleep is reported and never
# fails the gate. "benign" means it never holds a request thread, or holds it
# for a bounded, intended time. "pending" means the thread it holds is a
# known cost whose fix belongs to the partition named; the entry goes when
# the fix lands (the gate then reports it as stale). Re-review an entry
# whenever the function it names changes.
