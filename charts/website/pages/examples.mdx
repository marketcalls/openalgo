## Price pane below the studies

Read the studies first and the price last. A chart built with `movablePrimaryPane` treats the
price pane as an identity rather than a slot: moving it takes the candles, the moving average
drawn on them, the price line and the study count along, while RSI and MACD keep their own
panes and scales. The time navigator stays at the foot of the chart, on whichever pane is at
the bottom. The saved layout keeps the arrangement. The option is off by default, so a host
that still passes pane `0` for the price keeps its price pane on top. See
[Moving the price pane](/docs/scales-and-panes#moving-the-price-pane-below-its-studies).

## Anchored study input

The growth path starts at one point: a bar time and a price that belong together. The
price input names its time (`timeKey`), so **Pick point** sets both from one click, and
`anchor: true` puts the orange ring on the chart. Drag the ring to move both at once, then
use **Undo** and **Redo**: a drag and a pick are one step each, because the pick goes
through `draw.moveInputAnchor`. Escape during a drag cancels it. See
[a time and a price that belong together](/docs/indicators#a-time-and-a-price-that-belong-together).

<RunnableExample height={400} tiers={['draw']} caption="Drag the ring, or press Pick point and click a bar. Each drag and each pick is one undo step." code={`const bar = document.createElement('div');
bar.style.cssText = 'display:flex;flex-wrap:wrap;gap:6px;align-items:center;margin-bottom:8px;font-size:12px';
el.appendChild(bar);
const host = document.createElement('div');
host.style.cssText = 'height:330px';
el.appendChild(host);

lib.registerIndicator({
  id: 'example-anchored-growth', name: 'Anchored growth', placement: 'onchart',
  inputs: [
    { key: 'from', type: 'timestamp', label: 'Anchor time', default: 0, pick: true },
    { key: 'price', type: 'price', label: 'Anchor price', default: 0, pick: true, timeKey: 'from', anchor: true },
    { key: 'rate', type: 'number', label: 'Growth per bar (%)', default: 0.15 },
  ],
  plots: [{ key: 'path', title: 'Growth path', type: 'line', style: { color: '#f59e0b', lineWidth: 2 } }],
  calc(bars, s) {
    const start = bars.findIndex(b => b.time >= s.from);
    return { path: bars.map((_, i) => (start < 0 || i < start ? null : s.price * (1 + s.rate / 100) ** (i - start))) };
  },
});

const chart = lib.createChart(host);
const bars = lib.generateBars(1700000000, 160, 3600);
chart.addSeries('candlestick').setData(bars);
chart.setVisibleLogicalRange({ from: 40, to: 165 });
// The drawing controller draws the anchor and holds its undo steps.
const draw = new lib.DrawingController(chart);
const study = chart.addIndicator('example-anchored-growth', { from: bars[90].time, price: bars[90].close });

const readout = document.createElement('span');
const show = () => {
  const s = study.settings();
  readout.textContent = 'Anchor: ' + new Date(s.from * 1000).toISOString().slice(0, 16).replace('T', ' ')
    + ' UTC at ' + s.price.toFixed(2);
};
const button = (label, run) => {
  const b = document.createElement('button');
  b.type = 'button';
  b.textContent = label;
  b.style.cssText = 'padding:4px 10px;border-radius:6px;border:1px solid light-dark(#e4e4e4,#2a3046);background:light-dark(#fff,#1c2030);color:light-dark(#151515,#c7ccd8);cursor:pointer';
  b.onclick = run;
  bar.appendChild(b);
};
// One click answers with the bar time and the price together, and moving the
// anchor through the drawing controller makes the pick an undo step like a drag.
button('Pick point', () => chart.beginPick('point', p => draw.moveInputAnchor(study.id, 'price', p)));
button('Undo', () => draw.undo());
button('Redo', () => draw.redo());
bar.appendChild(readout);
chart.on('objects:change', show);
show();
return chart;`} />

## Multiple price axes

Three simulated series use independent ranges: blue near 100, green near 1,200,
and amber near 5. Start with two columns on the right and one on the left. Move
the green column, change its order, or narrow the chart. Drag or scroll over a
column to adjust only its scale. See the [axis placement API](/docs/scales-and-panes#multiple-axes-on-the-same-side).

<RunnableExample height={560} tiers={['widget']} caption="Simulated quotes, bars and headlines. One simulated exchange prices both the chart and the rows, and the rows take their prices only from the quote source, never from a candle." code={`${STOCK_BARS_SOURCE}

// A simulated exchange owns every price. The bar feed and the quote source each
// read it; a quote is never taken from a candle.
const seed = symbol => Array.from(symbol).reduce((n, c) => n + c.charCodeAt(0), 0);
// Each 700 ms step draws a seeded random move; the price is the day's drift
// plus the sum of the last thirty moves, so it wanders like a traded price and
// every reader of the same moment sees the same number.
const noise = n => {
  let h = Math.imul((n ^ 0x9e3779b9) >>> 0, 0x85ebca6b) >>> 0;
  h = Math.imul(h ^ (h >>> 13), 0xc2b2ae35) >>> 0;
  return ((h ^ (h >>> 16)) >>> 0) / 4294967296 - 0.5;
};
const exchange = {
  previousClose: symbol => 40 + seed(symbol) % 160,
  last(symbol, now = Date.now()) {
    const step = Math.floor(now / 700);
    let walk = 0;
    for (let k = 0; k < 30; k++) walk += noise(seed(symbol) * 100003 + step - k);
    const move = (seed(symbol) % 7 - 3) / 100 + walk * 0.004;
    return Math.round(exchange.previousClose(symbol) * (1 + move) * 100) / 100;
  },
};
const round = value => Math.round(value * 100) / 100;
const seconds = interval => interval === '1d' ? 86400 : 300;
// Simulated history, scaled to end at the exchange's price now.

  const series = stockBars(1700000000, 180, seconds(interval), exchange.previousClose(symbol), seed(symbol));
  const scale = exchange.last(symbol) / series[series.length - 1].close;
  return series.map(bar => ({ ...bar, open: round(bar.open * scale), high: round(bar.high * scale),
    low: round(bar.low * scale), close: round(bar.close * scale) }));
};
// One clock drives the quote source and the forming bar, so a row and the chart
// read the same step of the exchange at the same moment.
const ticks = new Set();
let clock = 0;
const onTick = fn => {
  ticks.add(fn);
  if (!clock) clock = setInterval(() => { const now = Date.now(); ticks.forEach(f => f(now)); }, 700);

  subscribeQuotes(instruments, { onQuote, onStatus }) {
    const [item] = instruments;
    if (onStatus) onStatus('live');
    return onTick(now => onQuote(quote(item, now)));
  },
};
const news = {
  getNews: async ({ symbol, cursor, limit }) => {
    const page = Number(cursor || 0);
    const items = Array.from({ length: limit }, (_, k) => {
      const i = page * limit + k;
      return { id: symbol + '-' + i, headline: symbol + ' update ' + (i + 1) + ': simulated headline',
        source: 'Simulated desk', time: 1700000000 - i * 5400, summary: 'Simulated text for this example. It is not market news.' };
    });
    return { items, nextCursor: page < 2 ? String(page + 1) : null };
  },
};

    subscribeBars(request, onBar) {
      const history = bars(request.symbol, request.interval);
      const forming = { ...history[history.length - 1] };
      return onTick(now => {
        const price = exchange.last(request.symbol, now);
        forming.close = price;
        forming.high = Math.max(forming.high, price);
        forming.low = Math.min(forming.low, price);

// over the chart, so leave it for the reader to open from the Watchlist button.
if (el.clientWidth > 640) widget.openWatchlist();

### A descriptor with several outputs

The 112 built-ins are not special-cased. Each is a descriptor - inputs, plots and a
`calc` - and anything you register with `registerIndicator` uses the same contract,
so it gets generated settings, a legend entry and state persistence for free.

This one computes a trend regime, then uses four descriptor hooks on the result:
`colorBy` for the line, `barColors` to repaint the candles, `background` to shade the
pane, and `markers` to flag each flip. No fork, no build step.

<RunnableExample height={340} tiers={['indicators']} code={`lib.registerIndicator({
  id: 'demo-regime',
  name: 'Trend Regime',
  category: 'Custom',
  placement: 'onchart',
  inputs: [
    { key: 'length', type: 'number', label: 'Length', default: 20, min: 2, max: 200, step: 1 },
    { key: 'up', type: 'color', label: 'Bull', default: '#26a69a' },
    { key: 'down', type: 'color', label: 'Bear', default: '#ef5350' },
  ],
  plots: [{
    key: 'basis', type: 'line', title: 'Basis', style: { lineWidth: 2 },
    // colorBy is a function, not the name of a column. It runs per bar and
    // returns a colour, or undefined to fall back to the plot's own.
    colorBy: ({ index, values, settings }) => {
      const t = values.trend[index];
      return t == null ? undefined : t > 0 ? settings.up : settings.down;
    },
  }],
  calc(bars, s) {
    const close = lib.sourceValues(bars, 'close');
    const basis = lib.nulls(lib.sma(close, Math.max(2, s.length | 0)));
    const trend = basis.map((b, i) => (b == null ? null : close[i] >= b ? 1 : -1));
    return { basis, trend };
  },
  // Repaint the price candles by regime.
  barColors({ values, settings }) {
    return values.trend.map((t) => (t == null ? null : t > 0 ? settings.up : settings.down));
  },
  // Shade the whole pane behind them.
  background({ values, settings }) {
    return values.trend.map((t) =>
      t == null ? null : lib.withAlpha(t > 0 ? settings.up : settings.down, 0.07));
  },
  // Flag every flip, anchored to the candle rather than to the indicator line.
  markers({ bars, values, settings }) {
    const out = [];
    for (let i = 1; i < bars.length; i++) {

## Render backends and vector export

The series pass goes through a render backend port. `renderer: 'auto'` takes the WebGL2
backend from `openalgo-charts/webgl` where the device has WebGL2 and the 2D path
otherwise, decided once at construction; `chart.rendererKind` reports which one is
painting. Pan and zoom: the candles are batched into one GPU draw call per frame and
composited into the pane's own canvas, so screenshots, drawings, axes and text are
unchanged.

<RunnableExample height={320} code={`const chart = lib.createChart(el, { renderer: 'auto' });
const bars = lib.generateBars(1700000000, 600, 3600);
chart.addSeries('candlestick').setData(bars);
chart.timeScale.fitContent(240);

// Decided once, at construction: 'webgl2' where WebGL2 works, else 'canvas2d'.
el.style.position = 'relative';
const tag = document.createElement('div');
tag.style.cssText = 'position:absolute;right:64px;bottom:30px;z-index:5;font:12px ui-monospace,monospace;background:light-dark(rgba(255,255,255,.9),rgba(0,0,0,.55));color:light-dark(#151515,#e6edf3);box-shadow:0 0 0 1px light-dark(#e4e4e4,transparent);padding:4px 8px;border-radius:6px;pointer-events:none';
function show(note) { tag.textContent = 'rendererKind: ' + chart.rendererKind + (note ? '  ' + note : ''); }
show(lib.isWebGL2Supported() ? '' : '(no WebGL2 on this device)');
// A lost context moves the chart to the 2D path for the session and says so once.
chart.on('renderer:fallback', function (e) { show('(fell back: ' + e.reason + ')'); });
el.appendChild(tag);
return chart;`} />

`chart.exportSVG()` writes the same frame as a standalone vector document: axis labels
and tags stay text, lines stay lines, and nothing transient (crosshair, hover, drag) is in
it. The right half below is the string the left half returned, inlined as markup and
re-exported as you pan or zoom the live chart.

<RunnableExample height={360} code={`el.style.display = 'flex';
el.style.gap = '10px';
const live = document.createElement('div');
live.style.cssText = 'flex:1 1 0;min-width:0;height:100%;position:relative';
const out = document.createElement('div');
out.style.cssText = 'flex:1 1 0;min-width:0;height:100%;overflow:hidden;border:1px dashed #5b6478;border-radius:6px;line-height:0';
el.appendChild(live);
el.appendChild(out);

const chart = lib.createChart(live);
const bars = lib.generateBars(1700000000, 120, 3600);
chart.addSeries('candlestick').setData(bars);
chart.addPriceLine({ price: bars[bars.length - 1].close, color: '#f5a623', lineWidth: 1, dashed: true, id: 'last' });
chart.timeScale.fitContent(120);

// One export per frame at most: the string is the whole paint, so exporting
// on every zoom event during a wheel glide would repeat the work.
let queued = false;
function exportNow() {
  // Sized to the target panel rather than the live chart: the chart lays
  // itself out for the export and puts the live layout back before returning.
  // queued stays set until the export is done, so nothing the export itself
  // does can schedule the next one: an export that re-queued on its own
  // relayout would run once per frame for as long as the page is open.
  try { out.innerHTML = chart.exportSVG({ width: out.clientWidth, height: out.clientHeight }); }
  finally { queued = false; }
}
function queueExport() { if (!queued) { queued = true; requestAnimationFrame(exportNow); } }
chart.on('resize', queueExport);   // the first measured layout, and any later one
chart.on('zoom', queueExport);
chart.on('pan', queueExport);
requestAnimationFrame(function () { requestAnimationFrame(queueExport); });
return chart;`} />

The options, the fallback rules and the serialising context behind the export are on
[Render Backends & SVG Export](/docs/rendering).
