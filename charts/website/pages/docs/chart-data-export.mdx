# Chart data export

`exportChartDataCsv(chart, options?)` is a base export that returns a CSV string
from the chart's installed data. It does not fetch history or start a download.
Your application selects the chart, chooses the filename and delivers the file.

## Create a CSV download

Call this function from the selected chart's download action, after its source
has finished loading. It uses the chart passed to the function rather than
looking up whichever chart becomes focused later.

```ts
import { exportChartDataCsv, type Chart } from 'openalgo-charts';

export function downloadChartData(chart: Chart, filename = 'chart-data.csv') {
  const csv = exportChartDataCsv(chart);
  const url = URL.createObjectURL(new Blob([csv], { type: 'text/csv;charset=utf-8' }));
  const link = document.createElement('a');
  link.href = url;
  link.download = filename;
  document.body.appendChild(link);
  try {
    link.click();
  } finally {
    link.remove();
    setTimeout(() => URL.revokeObjectURL(url), 0);
  }
}
```

An application can also send the returned string to its own storage or download
service. Browser download initiation does not confirm that a file was saved.

## Rows and columns

By default, rows cover **all loaded primary bars**, independently of the viewport. The fixed
columns are `time,open,high,low,close,volume,oi`. Time is UTC seconds, and numbers
retain input precision rather than axis display rounding. Missing or nonfinite
values are empty cells; genuine zero values remain `0`. Output uses CRLF row
endings and escapes quoted header fields.

| Additional columns | Behavior |
| --- | --- |
| `indicator:<instanceId>:<plotKey>` | Every configured study's declared plots, including hidden studies. Repeated study instances stay separate. Warmup and missing values are blank. |
| `comparison:<ordinal>:<symbol>:close` | Comparison closes aligned to each primary timestamp, in the comparison's own price units. |

By default, study values belong to the input row, before visual plot offsets. A study output
that is not a declared plot, such as a candle-color classification, is not added
as a CSV column. Comparison values are not converted into displayed percentage
or indexed-axis values. Transformed charts export their installed transformed
OHLC bars.

Use `{ indicators: false }` to omit study columns. Comparisons created through
`addComparison` or `comparisonController` are discovered automatically. For an
explicitly owned controller, pass its list through the `comparisons` option:

```ts
import { exportChartDataCsv, type Chart, type ComparisonController } from 'openalgo-charts';

export function exportComparisons(chart: Chart, comparisons: ComparisonController) {
  return exportChartDataCsv(chart, { indicators: false, comparisons: comparisons.list() });
}
```

Pass `{ comparisons: [] }` to omit comparisons. A chart without primary rows
still returns its header. Drawings, orders, positions, account state and
credentials are not exported.

## Select rows and studies

Pass study **instance IDs** to select columns in a specific order, and UTC-second
bounds to select rows. Hidden studies remain eligible. The exporter calculates
over the full loaded history first, so a recent range retains warmed-up values.

```ts
const csv = exportChartDataCsv(chart, {
  indicators: [fastStudy.id, slowStudy.id],
  range: { from: 1700000060.25, to: 1700000600.5 },
});
```

Both range limits are inclusive and either may be omitted. Fractional and
negative timestamps retain their exact numeric values. Equal limits select an
exact timestamp if present; an empty intersection returns headers only.
`ChartDataCsvRange` is the exported type for these bounds.

Use `indicators: []` or `false` for no studies. Omit the option, or pass `true`,
to include all studies in chart order. The selector uses `IndicatorApi.id`,
not the descriptor ID or displayed name, so repeated studies stay distinct.
Duplicate, unknown or removed IDs throw. Invalid range values and reversed
bounds also throw; accessor-backed range fields are rejected without invoking
their getters. The host should show these errors through its normal error UI.

## Displayed plot positions

Set `alignment: 'display'` to follow current study plot offsets, including direct
`applyOptions({ barOffset })` changes. It uses the shared chart axis, so extra
timestamps from other series do not move values to the wrong bar. Primary prices
and comparison closes stay on installed primary positions. Candle plots expand
into four independently available OHLC columns.

Display CSV starts with `time,logical_index,time_origin`. A time origin is
`axis`, `interpolated`, `projected` or `unknown`. Fractional offsets are retained;
large offsets create only the occupied rows. An unrepresentable position or a
colliding timestamp throws rather than overwriting another observation.

Outside the loaded axis, times use its nearest observed spacing. These are
spacing estimates, not market-session guarantees or future observations.
A single loaded timestamp cannot establish spacing, so outside times stay blank.
Supply `projectTime(logicalIndex, context)` to return a finite UTC timestamp or
`null` for such positions. Its frozen `ChartDataProjectionContext` contains only
installed axis times and the revealed replay boundary.

Time bounds apply after shifting. Unknown-time rows remain only when no bound is
set. Offset-only future rows have no primary or comparison prices.

## Formatted exports

`formatters.time` adds a `time_label` beside raw numeric time.
`formatters.value(value, column)` formats finite primary, study and comparison
cells. `formatters.header(column)` changes header labels. `ChartDataColumn`
metadata retains each canonical key and source identity; duplicate displayed
headers are disambiguated. Missing observations stay blank without calling the
value formatter.

```ts
const csv = exportChartDataCsv(chart, {
  formatters: {
    time: seconds => new Date(seconds * 1000).toISOString(),
    value: (value, column) => column.kind === 'indicator'
      ? value.toFixed(4) : String(value),
  },
});
```

Callbacks must return strings. CSV escaping preserves commas, quotes and line
breaks; potentially executable spreadsheet text receives an apostrophe prefix.
Raw negative numbers remain numeric when no formatter is supplied. An exception
aborts the export. Data is captured before presentation callbacks, so mutations
inside a formatter cannot replace another exported cell.

## Replay and host ownership

Replay installs only its revealed prefix, so CSV reads only those rows. Partial
bars contain only the observations revealed so far. Do not substitute the full
history retained by a replay controller or feed cache when exporting a chart.

Capture the chart and instrument when opening a download menu. Before exporting,
reject a stale target or a source still loading or in an error state. The export
function has no knowledge of the host's loading controls or current account.
Report exceptions through the host's normal error UI.

The packaged widget and reference demo provide these choices in their CSV
download dialogs. They retain the offered study instances and visible bounds,
and validate the captured chart again before starting the download. Their From
and To bounds are a date and a time on the chart's clock, in the chart's
timezone, which the dialog names (since 2.6.0); a To written to the minute takes
in every bar that opens inside that minute. The dialog turns them into the UTC
seconds `range` takes.

CSV is a numeric snapshot, not a restorable chart layout. Use
[chart state](/docs/state) or [workspaces](/docs/workspaces) for configuration,
and [PNG or SVG export](/docs/rendering) for a visual capture.
