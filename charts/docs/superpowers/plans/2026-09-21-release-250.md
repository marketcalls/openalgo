# Release 2.5.0

## Approved scope

Combine price-alert timeframe visibility with the two reviewed local changes:

- `e747324`, published as PR #18 at `5ac0f07`: alert tick snapping and keyboard removal.
- `2247f8b`, published as PR #19 at `840705e`: table cell clipping and automatic column widths.
- `12ab116`: fixed price alerts remain visible across timeframes for the same
  symbol and exchange, while evaluation and dragging retain the original interval.

The prepared 2.4.9 changes were never published. They ship together in 2.5.0.
The original Charts checkout and the OpenAlgo and OpenScript working trees remain
outside this change. Library and reference-host work uses an isolated checkout.

## Corrections made during review

Alert snapping follows the source scale, including left and independent axes.
The preview and committed threshold agree. Range bounds respect decimal ticks
and off-tick opposite bounds. A callback-only host without tick metadata cancels
a move that its callback cannot place inside the range.

Drawing selection, hover, placement and editable fields retain keyboard priority.
Alert hover survives a drag, a same-source history refresh and unrelated object
updates. Hidden, paused, removed or nonnumeric sources are not deletion targets.

Automatic table widths measure the font actually rendered in each row. Width
measurement preserves canvas state. The automatic font baseline is 11 px and
the minimum automatic column width is 28 px. All cells clip their own text.

The yfinance host clears old price and volume bars before announcing a new data
context in either pane. Same-source refresh preserves bars and viewport. Returning
from finer bars cannot consume an original-frame alert's next closed bar.
