# Release 2.5.1

## Approved scope

Validate PR #21 at `0b63e16308090fbfe7afa4ac2190f427e7d73937`, then merge and
publish 2.5.1. Its base is the published 2.5.0 commit
`9d36ca564abe873a8f0bd289f5926c04d0a2414b`.

`AlertControllerOptions.spentLines` defaults to `show`. Opting into `hide`
removes triggered and expired alert visuals while retaining the records,
saved runtime and once-only delivery protection. Armed and repeating alerts
keep their lines. Re-arming restores the appropriate line.

Work uses the existing isolated Charts checkout. The active OpenAlgo and
OpenScript checkouts remain outside this release. No runtime dependency or
saved-alert format changes are intended.

## Review focus

A hidden once-only record must not fire again after restore. Hiding a drawing
alert must leave its original drawing intact. Both range lines must disappear.
Disabled alerts must retain their existing appearance. Repeating alerts must
remain armed and visible after delivery. The constructor option is host policy,
not a new field in saved alert documents.
